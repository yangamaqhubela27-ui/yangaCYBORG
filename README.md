
Project Overview

YangaCYBORG Awareness Bot is a simple C# console-based chatbot designed to
provide basic cybersecurity awareness information. The chatbot interacts
with the user by asking for their name and allowing them to choose a
cybersecurity topic they would like to learn about.

The project also includes an audio greeting and an ASCII logo to make
the chatbot more interactive.

Features

• Plays a recorded audio greeting when the program starts.
• Displays an ASCII logo.
• Asks the user for their name.
• Prevents the user from continuing without entering a name.
• Provides a menu of cybersecurity awareness topics.
• Uses if and else if statements to respond to the user’s
selection.
• Provides basic information about:
  • Phishing
  • Password Safety
  • Cyberbullying
  • Online Privacy
• Displays a friendly closing message using the user’s name.

Technologies Used

• C#
• .NET
• Visual Studio
• System.Media.SoundPlayer for audio playback
• Console input and output
